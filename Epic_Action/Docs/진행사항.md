# 진행사항 — 무기 아바타 씬

/clear 후 이어서 작업할 때 이 문서부터 읽는다. (작성: 2026-10-30, 같은 날 총·전기톱 개선 후 갱신)

## 목표
사람 캐릭터 없이 **무기 자체가 플레이어**인 씬. 무기가 이동·점프·공격을 모두 한다.
기존 `SampleScene`(사람이 무기를 드는 구조)과 원본 WeaponData는 건드리지 않는다.

## ⚠ 먼저 해결할 것 (미해결 버그)
**씬 빌더가 총 단계에서 예외로 중단된다.** 총 가늠좌 조준을 넣으면서 생긴 문제다.
- 증상: 메뉴 `Tools/Epic Action/Build Weapon Avatar Scene (resets Avatar WeaponData)`를 실행해도 `WeaponAvatarScene.unity`와 `Avatar_Rifle.asset`이 갱신되지 않는다. 다른 무기 데이터(`Avatar_ChainsawRuler` 등)만 먼저 저장된다. `invoke_menu`는 예외가 나도 success를 돌려주므로 **파일 수정 시각으로 확인해야 한다**.
- 원인: `WeaponAvatarSceneBuilder.PartBounds`가 모델에서 `Rear_Aperture`, `Front_Sight_Post` 이름의 렌더러를 찾는데, `M4_Casual.obj`는 유니티에서 **렌더러 1개(`default`)로 합쳐져** 들어온다. 그래서 "Missing model part" 예외가 난다.
- 해결 방향(승인 필요): 빌더가 `.obj` 텍스트의 `o Rear_Aperture_134`, `o Front_Sight_Post_131` 구간 정점을 직접 읽어 두 점을 구한다. 기대값은 조준환 중심 (0, 0.199, -0.1095), 가늠쇠 끝 (0, 0.2455, 0.344).
- 해결 전에는 총을 쓰면 `rifleSightRear/Front`가 (0,0,0)이라 우클릭 조준 시점이 엉뚱한 곳에 잡힌다. 다른 무기는 영향 없다.
- 재빌드 때 Unity에 "씬을 저장하시겠습니까?" 창이 뜨면 거기서 멈춘다(`SaveCurrentModifiedScenesIfUserWantsTo`). 창을 처리해야 진행된다.

## 실행 방법
1. 메뉴 `Tools/Epic Action/Build Weapon Avatar Scene (resets Avatar WeaponData)` 실행
   - `Assets/Scenes/WeaponAvatarScene.unity` 새로 생성
   - `Assets/Data/Avatar/*.asset`(아바타용 WeaponData) 재생성 → **인스펙터에서 손본 값은 사라짐**
   - **데이터(포즈·콤보·크기)를 코드에서 바꾼 뒤에는 반드시 다시 실행해야 씬에 반영됨**
2. 조작: WASD 이동 · Space 점프 · 좌/우클릭 공격 · Q 진화 · 숫자키 1~4 무기 교체
   - 총(4번)만 다르다: 좌클릭 연사 · **우클릭 유지 = 가늠좌 조준** · **V = 개머리판 근접공격** · Space = 아래로 쏘며 점프

## 구조
계층: `WeaponAvatar(CharacterController) > Pose(WeaponSwinger: 공격 포즈) > Motion(이동 연출 오프셋) > 무기 모델`

| 파일 | 역할 |
|---|---|
| `Assets/Scripts/Avatar/WeaponAvatar.cs` | 입력(V 키는 `Keyboard`로 직접 읽어 `AvatarInput.melee`), CC 이동·중력, 숫자키 교체, Q 진화, Lunge/Hop. 계열 판별: chainsaw / shears / rifle / 그 외=자 |
| `Assets/Scripts/Avatar/AvatarMoveset.cs` | 추상 베이스. 콤보 실행(WeaponSwinger), 히트 처리(HandleHit), 공용 헬퍼. `AvatarInput.melee`, `virtual Aiming`(HUD 크로스헤어 숨김용) |
| `Assets/Scripts/Avatar/RulerMoveset.cs` | 자: 끝을 축으로 텀블링 이동, 휘었다 튕기는 점프 |
| `Assets/Scripts/Avatar/ShearsMoveset.cs` | 가위: 두 날이 다리처럼 30° 교차하며 걷기(ShearsDriver 각도 제한을 우회해 날을 직접 회전), 가위질 |
| `Assets/Scripts/Avatar/ChainsawMoveset.cs` | 전기톱: 체인 날을 세워 구동, 스프링 점프+공중제비, 4연타+공중 회전 공격, 갈아버리기. 1타 선딜 웅크림(`KickMotion`) |
| `Assets/Scripts/Avatar/RifleMoveset.cs` | 총: 개머리판으로 서서 통통 튀는 이동, 4발 쏘며 점프, 좌클릭 연사(즉시 판정·트레이서·반동), 우클릭 가늠좌 조준, V 개머리판 콤보 |
| `Assets/Scripts/Avatar/AvatarHud.cs` | OnGUI HUD(무기 이름, 슬롯, 조작, 상태) + 화면 중앙 크로스헤어(조준 중 숨김) |
| `Assets/Scripts/Player/ThirdPersonCamera.cs` | `Sight`(시점 지점)가 있으면 눈을 그 뒤 0.1m로 보내고 FOV 40, near clip 0.02. `Pitch` 노출. `Sight`가 비면 기존과 동일 |
| `Assets/Scripts/Editor/WeaponAvatarSceneBuilder.cs` | 씬·아바타 데이터 생성. 무기별 포즈·콤보 수치는 여기 있음. `PartBounds`(위 버그 참고) |

다른 곳의 수정:
- `GameSceneBuilder.cs`: 헬퍼 9개(BuildWorld, BuildCamera, BuildEnemy, MakeLit, LoadOrCreate, Save, Set, Swing, EnsureFolder)를 internal로 변경
- `Enemy.cs` Start: PlayerController가 없으면 WeaponAvatar를 추적
- `WeaponData.cs`: "Rifle (weapon avatar)" 항목(rifle, rifleMuzzle, **rifleSightRear, rifleSightFront**, fireInterval, fireRange)
- 총 모델: `Assets/Weapons/M4_Casual/M4_Casual.obj/.mtl` (정점 직접 확인: 후방 조준환 중심 (0, 0.199, -0.1095)과 전방 가늠쇠 끝 (0, 0.2455, 0.344)을 잇는 조준선이 총 축에서 약 5.85° 위로 기울어 있어, 조준 시점을 이 선에 맞춰 보정한다)

## 무기별 현재 상태
| 키 | 무기 | 상태 |
|---|---|---|
| 1 | 일반 자 → Q 무기 자 → Q 전기톱 | 텀블링 이동. 무기 자는 3타가 도약 회전 |
| 2 | 진화 가위 (일반 가위는 아바타 씬에서 제외) | 교차 걸음. 좌: 펼친 베기 3연타(3타 360° 회전) / 우: 가위질 3연타 |
| 3 | 전기톱 | 크기 `heldScale 2.2`, `hitRadius 0.65`. 이동 MoveSpeed 11, Accel 20, 선회 0.45. 지상 4연타: **1타 = 선딜 0.16초 웅크림 후 `leap 1.8`·`lunge 1.4`로 땅을 박차며 몸 360° 대각선 회전베기**(`chainAt 0.8`) → 가로(0.6m 튕김) → 올려베기(1.5m) → 내려찍기(2.5m 튕긴 뒤 하강). 공중 좌클릭: 360° 회전 베기(점프당 1회, altCombo[0]). **일반 좌클릭도 홀드처럼 적에 닿으면 멈춰 갈다가 `sliceDelay` 후 벤다**(`SlicesNow` 항상 false, 홀드 여부 조건 제거) |
| 4 | M4 소총 | 서 있을 때 개머리판을 땅에 대고 세운 자세(-78°). 이동은 0.3초마다 0.4m 홉 + 착지 찌그러짐, 사격 없음. Space = 총구를 아래로 뒤집고 4발(0.05초 간격)로 점점 속도를 올려 2.4m 점프. 좌클릭 연사 중에는 수평으로 눕고 ×0.6로 미끄러지며 **사격 반동 0.25**(적 넉백은 `knockback 3 × 0.15`로 그대로). V = 개머리판 콤보. **우클릭 유지 = 가늠좌 시점**(마우스로 시점 이동, 총이 그 방향으로 겨눔, 보조 조준 없이 화면 중앙으로 사격, 느리게 미끄러짐, 점프 불가, 크로스헤어 숨김, V 스윙 동안 3인칭 복귀) |

제외됨: 확성기, 네일건(아바타 코드·데이터 삭제. 원본 SampleScene에는 그대로 있음)

## 확인되지 않은 것 (플레이 테스트 필요)
- 모든 수치는 플레이하지 않고 정한 초기값
- **가늠좌 시점**: 시점 높이 `SightHeight 1.2`(RifleMoveset), 눈 거리 `sightEyeRelief 0.1`·FOV `zoomFov 40`(ThirdPersonCamera)이 화면에 맞는지. 조준환 링이 너무 크거나 작게 보이는지. 빌더 버그 때문에 아직 실제 화면을 확인한 사람이 없다
- 전기톱 1타: 웅크림이 눈에 띄는지, 도약 높이가 충분한지(1.2일 때 "약간만 뜸"이라는 피드백으로 1.8로 올림), 1타 직후 지상 전용인 2타가 착지 전에는 안 나갈 수 있음
- 전기톱 크기를 키운 뒤 공격 포즈의 절대 위치값(-0.3 등)이 어색한지
- 전기톱 갈기: 버튼을 떼도 끝까지 간다. 적이 안 베어지면 동작이 멈춘 채 남을 수 있음(최대 시간 안전장치 없음)
- 전기톱: 갈아버리기가 적에 붙어 유지되는지, 공중제비가 180° 근처에서 반대로 튀어 보이지 않는지(Slerp 추적 방식)
- 가위: `jawClosed`를 "두 날이 나란히 겹친 자세"로 가정 → 아니면 다리가 한쪽으로 쏠려 보임
- 총: 총구 위치는 모델 바운즈로 추정(`rifleMuzzle`), 개머리판 판정 위치(`bladeBase/Tip`)도 추정
- 원래 사람 씬(SampleScene)은 이번 작업으로 바뀐 동작 없음(빌더 헬퍼 접근 범위만 변경, 카메라는 `Sight`가 비면 기존과 동일)
